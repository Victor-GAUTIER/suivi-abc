Suivi ABC – Politique de confidentialité

Dernière mise à jour : octobre 2026.

Données saisies

Les profils et les comportements que vous saisissez sont enregistrés sur votre appareil, dans le navigateur. L'éditeur de l'application n'a pas de serveur et ne reçoit aucune de ces données.

Synchronisation Google Drive (facultative)

Si vous activez la synchronisation :

  • vos données sont chiffrées sur votre appareil, avec le mot de passe que vous choisissez, avant d'être envoyées ;
  • le fichier chiffré est stocké dans un dossier caché de votre Google Drive, réservé à cette application (accès « drive.appdata ») ;
  • l'application n'accède à aucun autre fichier de votre Google Drive ;
  • l'éditeur ne peut ni lire ce fichier ni récupérer votre mot de passe : un mot de passe perdu rend le fichier illisible.

Partage et suivi

Aucune donnée n'est vendue, partagée ou transmise à des tiers. L'application n'utilise ni publicité ni outil de mesure d'audience.

Supprimer vos données

  • Sur l'appareil : effacez les données du site dans les réglages de votre navigateur.
  • Dans Google Drive : retirez l'accès de « Suivi ABC » dans votre compte Google (Sécurité → Applications tierces), puis supprimez ses données cachées.
